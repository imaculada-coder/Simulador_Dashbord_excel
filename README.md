# Simulador_Dashbord_excel

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático de análise de dados e construção de dashboards no Microsoft Excel.

O objetivo é analisar a evolução das bolsas concedidas pelo Programa Universidade para Todos (ProUni), utilizando dados abertos disponibilizados pelo Ministério da Educação (MEC).

A análise considera os anos de **2005, 2015 e 2025**, permitindo observar diferenças na distribuição das bolsas integrais e parciais entre as regiões e os estados brasileiros.

## Objetivos

- Comparar o número de bolsas nos três anos analisados.
- Identificar aumentos e reduções na concessão de bolsas.
- Analisar a distribuição regional e estadual.
- Comparar bolsas integrais e parciais.
- Apresentar os resultados em um dashboard interativo.

## Ferramentas utilizadas

- Microsoft Excel
- Tratamento e organização de dados
- Fórmulas e cálculos automatizados
- Gráficos e indicadores dinâmicos
- Validação de dados e filtros interativos

## Estrutura do arquivo

O projeto está organizado em sete abas:

| Aba | Finalidade |
|---|---|
| Dashboard | Visualização interativa dos indicadores |
| Assets | Elementos de apoio e identidade visual |
| Base_2005 | Dados tratados de 2005 |
| Base_2015 | Dados tratados de 2015 |
| Base_2025 | Dados tratados de 2025 |
| Dados_Tratados | Consolidação dos dados |
| Cálculos | Indicadores e cálculos utilizados |

## Funcionalidades

O dashboard permite selecionar região, estado, ano, tipo de bolsa e modalidade, facilitando a comparação dos resultados.

Um gráfico reúne os três anos analisados, permitindo visualizar as mudanças na concessão de bolsas ao longo do período.

## Fonte dos dados

Ministério da Educação (MEC) — Dados Abertos do ProUni.

Fonte: https://dadosabertos.mec.gov.br/

**Nota metodológica:** os resultados representam registros de bolsas presentes nas bases analisadas, não necessariamente estudantes únicos. A comparação considera três anos específicos, não uma série anual contínua.

## Como utilizar

1. Baixe o arquivo Excel disponível neste repositório.
2. Abra no Microsoft Excel.
3. Acesse a aba **Dashboard**.
4. Utilize os filtros para explorar os indicadores por ano, região, estado e tipo de bolsa.
